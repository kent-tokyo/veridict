# リサーチマップ

[English](research-map.md) | 日本語

この文書は未実装の候補を記録します。実装予定表ではありません。実装済みの仕様は
[`metrics_ja.md`](metrics_ja.md)を参照してください。

着手には、具体的な利用場面、明確な統計的主張、適切な較正試験、ライセンス上問題のない実装経路が
必要です。それまでは現在の保守的な挙動を維持します。

## 数値メトリクス

| 候補 | 保留理由 | 着手条件 |
|---|---|---|
| `quantile-diff` のBCa | 標本分位点は非平滑で、現在のp95較正では被覆率が改善しない | 広い較正条件で再現可能な改善がある |
| 分位点の `power`、`matrix`、`plan` | 分位点分散には密度または分布の仮定が必要 | その仮定を宣言できる末尾レイテンシ用途がある |
| `power --metric relative-diff` | 相対変化の標準偏差、または `baseline > 0` の変換済み事前データが必要 | 比例単位の計画が必要になる |
| 変化したサブセットだけの効果 | 結果による条件付けで、抽出・ペア化・主張の意味が未確定 | 実例と事前に宣言できる仕様がある |
| Log-ratioメトリクス | 単位が異なり、両値の正値制約もある | 既にlog-ratio単位で主張する用途がある |
| 数値メトリクスのクラスターブートストラップ | ペア化、クラスター数、退化、再標本化単位の契約が必要 | 相関データと行単位区間を上回る被覆率証拠がある |

数値クラスタリングに着手する場合の順序は、`mean-diff`、`relative-diff`、`quantile-diff`、
`sign-test` とします。

## 二項メトリクスとElo

| 候補 | 保留理由 | 着手条件 |
|---|---|---|
| Wilson連続性補正 | 共有する二項処理を変える一方、実測上の利点が未確認 | 権威ある数式とexact・Jeffreysとの較正比較がある |
| Normalized-Elo pentanomialまたはSiegmund補正 | 正しさの修正ではなく精緻化 | 引き分け率、ペア化、離散境界で実用上の差がある |
| 引き分けを考慮したElo検出力 | 現在の二項計画は引き分けをモデル化しない | 引き分け率を宣言でき、計画誤差が問題になる用途がある |

## `matrix` と計画

| 候補 | 保留理由 | 着手条件 |
|---|---|---|
| `matrix` 全体の判定 | 「最良」「差がある」「全候補を上回る」は別の主張 | 主張と多重性規則を宣言できる |
| `matrix` の失敗方針 | 失敗を常に片側の責任にはできない | 責任と両側失敗の扱いを定義できる |
| ブートストラップ・クラスター区間の補正 | 独立行としての再構成では再標本化単位が変わる | 実際の再標本化単位で一群誤り率を保証できる |
| 予算制約付き割り当て | 不確かなペアの順位は予算目的関数ではない | 目的関数と検証済みの割り当て法がある |

## 来歴と時間価値付き検定

| 候補 | 保留理由 | 着手条件 |
|---|---|---|
| 学習・チェックポイント来歴 | `verify-run` は実行記録を検証し、実験DBにはしない | 親成果物、データ、設定の不透明ハッシュを扱う汎用要件がある |
| 三項・五項の時間方策 | 3・5結果の状態、e-process、報酬の意味が未定義 | 具体的な時間価値用途と較正試験がある |
| 複合仮説・オンライン対立仮説 | 同じ列からの `p1` 推定は妥当性を変える | 混合分布または信頼列の構成がある |
| Elo指定・方策プリセット | 変換だけでは引き分けを扱えず、用途別方策はコア外 | 汎用化できる改良の利用実績がある |

## スコープ外

- ベンチマーク・対戦実行器、用途固有の判定器、メトリクス生成器。
- 実験データベース、ダッシュボード、クラウドサービス、分散ワーカー。
- 予測集合、局所リスクモデル、しきい値選択システム。
- 因果探索、介入選択、適応的な実験制御。
- 特定のエンジン、モデル、データセットに依存する既定値。

外部ツールは、用途非依存のスコア、勝敗、ステータス、実行記録を出力し、`veridict` に判定させられます。
依存方向は一方向のままです。
